# 🧙‍♂️ Hello there, traveler

Welcome to **The Nexus Community** — also known as **TeamNX**.

This GitHub organization hosts **public-facing projects, experiments, and active development** within our community.  
We operate across **both GitHub and GitLab**, with each platform serving different purposes depending on the project.

Additional projects may enter development as resources and scope evolve.
